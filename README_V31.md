# 모스트애드 인스타 계정 최적화 v31

## 적용 기능
- 고객 메뉴 `/instagram-marketing`
- 계정 1개 신청 시 150,000P 차감
- 관리자 승인 요청 상태
- 관리자·최고관리자 승인/반려
- 승인일부터 30일간 `인스타 최적화 가동중`
- 30일 경과 후 종료 처리
- 반려 시 150,000P 자동 환불
- 선팔로우·좋아요·스토리·댓글 설정 접수
